# AGENTS.md

Instructions for Codex and other coding agents in this repository.

This repository keeps one set of agent instructions: **read [CLAUDE.md](CLAUDE.md)
first and follow it**. Its rules apply to every agent, not only Claude Code.
In particular:

- **Architecture decisions (gate)**: the decision register in
  [docs/framework-direction.md](docs/framework-direction.md), the authority
  order, flagging conflicts, and stating each architecture PR's basis.
- **Docs tiers**, **Repository safety** (public repo: no real contacts,
  credentials or hosting details) and **Engineering discipline**.

Don't copy rules into this file; change them in `CLAUDE.md` so both entry
points stay the same.
