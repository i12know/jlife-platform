# Reading plans (generated)

Derived, date-mapped daily reading plans built from the canonical harmony
data in `content/harmony/` plus a citation-level reading of "The Life and
Teachings of Christ, Plus Nothing" (2023). These are build outputs, not
source-of-truth data -- source-of-truth stays in `robertson-1922-outline.json`,
`subsections.json`, and `kjv-word-counts.json` one level up.

## Files

- **`citation_seq.json`** -- the 359 scripture citations from "Plus Nothing,"
  in the book's own presented order, each with its section number/title,
  book/reference, and (where one exists) the Robertson/Master unit it
  dominantly overlaps with by verse count. Manually transcribed from the
  book's page images (its OCR text layer was too corrupted to parse
  reliably) and matched programmatically; see CHANGELOG.md for the session
  this was built in.
- **`2027-Jan-Mar_LATOC-anchored-reading-plan.csv`** -- a reading plan
  through PlusNothing's own 239 sections, in the book's own order,
  Dec 20, 2026 - Apr 2, 2027 (104 days), least-squares word-balanced within
  three segments fixed at two calendar anchors: Christmas Eve ends with
  "The Birth of Jesus" (#1.8), Easter Sunday ends with "The Resurrection of
  Jesus" (#6.1).
- **`2026-12-20to2027-04-02_harmony-parallel-reading-plan.csv`** -- a
  companion plan covering the same 104 days, reading the Robertson/SonLife
  Master harmony's full parallel-Gospel accounts instead, with day
  boundaries tracking the anchored plan above as closely as possible (see
  the script's docstring for how orphaned/duplicated sections are
  resolved).

## Regenerating

From the repo root, in order:

```
python3 content/harmony/reading-plans/scripts/build_latoc_plan.py
python3 content/harmony/reading-plans/scripts/build_anchored_latoc_plan.py
node bin/build-reading-plan.js --style=parallel --days=255 \
    --granularity=subsection \
    --out=content/harmony/reading-plans/master_full_units.json
python3 content/harmony/reading-plans/scripts/build_harmony_parallel_plan.py
```

The intermediate `latoc_units.json` and `master_full_units.json` build
artifacts are regenerated by this pipeline and are not committed.

## Content-rights note

`citation_seq.json` and the anchored plan reproduce PlusNothing's own
239 section titles and citation-to-section structure. See
`docs/content-rights.md` if extending this further (e.g. adding the
book's prose text, which is NOT reproduced anywhere here -- only
scripture references and short section titles).
